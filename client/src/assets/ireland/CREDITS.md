# Media credits

Sources and licences for the hero footage and the university imagery added to
the site.

Everything below is licensed for commercial use with **no attribution
required**, which is why no credit line is rendered on the page. An earlier pass
used Creative Commons landmark photography (Queen's Belfast, Croke Park, Trinity
Campanile) that did require visible attribution; those files were removed when
the imagery was replaced.
